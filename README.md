# 📊 Data Exploration, Cleaning & Dashboard

Ce repository regroupe mes exercices pratiques en analyse de données, réalisés pour renforcer mes compétences en Data Analytics.

### 🔍 Contenu du repo
- **01 - Data Exploration (EDA)** : Analyse exploratoire, statistiques descriptives, détection des valeurs manquantes et des outliers.
- **02 - Data Cleaning** : Nettoyage, traitement des doublons, formatage des dates, gestion des NaN, standardisation.
- **03 - Dashboards** : Visualisations et tableaux de bord (Power BI / Python - Matplotlib, Seaborn, Plotly).

### 🛠️ Outils utilisés
Python (Pandas, NumPy, Matplotlib, Seaborn), SQL, Excel, Power BI / Tableau

### 🎯 Objectif
Montrer mon processus complet : de la donnée brute à l'insight visuel.

### 📂 Structure
/data -> datasets bruts
/dashboards -> captures et fichiers .pbix
